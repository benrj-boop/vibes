# Vibes

Weekly team happiness pulse for APAC PMM.

## How it works

1. Open the page during Friday team sync
2. Each person picks an emoji + drops a song
3. "Clear" resets an individual pick (doesn't touch history)
4. "Log vibes" copies formatted markdown to clipboard + saves to local history
5. Paste into your log file to keep the permanent record

## Deploy

Push to GitHub and enable Pages on `main` branch. Single `index.html`, no build step.
